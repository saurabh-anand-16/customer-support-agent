Look: teal accent `#0E7C6B`, page `#F7F7F4`, sidebar `#EFEEE9`, text `#16181D`, amber `#8A4A06` on `#FBEFD9` for "needs a person". Filled, rounded buttons. Font Inter.

Sample values in the files (for example the references R-0002 and RT-0074, the timings, the token counts) are made up. The app must show only what the agent returns.

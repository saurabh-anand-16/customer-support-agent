## Conventions

- Blocks that start with **Editor's note** are not Amazon's text. They explain a formatting choice or point out that two pages disagree.
- Links between these pages are relative. Pages the originals refer to but that are not in this folder (for example "Request an A-to-Z Guarantee Refund") are left as plain text.
- In refund tables, "—" marks a cell that was blank in the original.
- Tables use `<br>` for paragraph breaks inside a cell, because Markdown has no other way to do it.
- Files use LF line endings; `.gitattributes` keeps them that way on Windows.

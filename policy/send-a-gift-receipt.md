# Send a Gift Receipt

> Send a gift receipt by following these steps. By sending a gift receipt, the gift receiver can return or choose to view their gift details.

To send a gift receipt to a gift recipient, do one of the following:

1. While placing the order, select the "This order contains a gift" checkbox (for items Fulfilled by Amazon and selected sellers).
2. Select Proceed to checkout.
3. Select Add Gift Options
4. Select This item is a gift and Email a copy of your gift message upon delivery.
5. Enter the recipient's email address and select Save gift options and continue.

## Send a gift receipt for items not marked as a gift after checkout

1. Go to Your orders.
2. Find the item and select Share gift receipt.
3. Select the link provided.

Now, you can send this link as gift receipt to the recipient (for example through email, chat, SMS or any other). You can also download a PDF copy of the gift receipt on the website. However, you cannot download a PDF copy in the Amazon shopping app.

> **Note:**
>
> Recipients will be able to see the gift receipt, return options, and have the choice to digitally view their gift, once the order has been delivered.
>
> You can only create gift receipts within the eligible return window for the item. If the option to create a gift receipt isn't available, the item isn't eligible for a return. See [Return a Gift](return-a-gift.md) for more information regarding gift returns.
